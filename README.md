# Simulado de Licenciamento de Seguros

Sistema web estatico para estudo da prova de licenciamento de seguros nos EUA.

## Como usar

Abra `index.html` no navegador ou publique a pasta no GitHub Pages.

## Recursos

- Perguntas em ingles, conforme o material original.
- Interface em portugues.
- Modos Prova e Estudo.
- Cronometro automatico no modo Prova.
- Botao para salvar uma tentativa incompleta e continuar depois.
- Exportacao do resultado em PDF pela janela de impressao do navegador.
- Filtros por questoes gerais, Massachusetts e Florida.
- Filtro por temas para estudar assuntos especificos.
- Foco de estudo em todas as questoes, questoes mais erradas ou questoes salvas para revisar.
- Botao para marcar questoes para revisar depois.
- Botao para refazer somente as questoes erradas da tentativa atual ou de uma tentativa salva no historico.
- Sorteio aleatorio com reducao de repeticao.
- Resultado final com percentual, erradas, explicacoes e desempenho por tema.
- Historico local no navegador com acesso as questoes erradas das tentativas salvas.
- Suporte para explicacoes em ingles e portugues gravadas no banco de questoes.

## Observacao

O historico e os simulados incompletos usam armazenamento local do navegador. Eles nao criam uma lista centralizada de alunos ou resultados.
